MEETING ROOM UI REDESIGN
Report
Date: 2026-11-04
Status: implemented, tested and deployed locally. The independent QA review found the issues in section 6;
NONE of them is fixed yet, pending the owner's approval. Nothing is committed.

==========================================================================================
1. REQUEST AND AGREED SCOPE
==========================================================================================
"Make a professional UI: alignment, position, font, border; also check the right-side panel."
Approved choices: labels under the icons; Inter font bundled with the app; meeting room only
(control bar, header and the three side panels). Behaviour must not change.

==========================================================================================
2. PROBLEMS FOUND BEFORE THE CHANGE
==========================================================================================
- Icon-only round buttons: several meanings unclear (the plain circle = local recording, the shield
  = host controls).
- The mic/camera device chevron was a separate small circle overlapping the button.
- Mixed shapes and sizes (44px circles, 28px chevron, wide red Leave pill); one centred row with
  no grouping.
- Muted state used the same solid red as Leave; active panel used the same blue as screen share.
- The app asked for the Inter font but never loaded it, so text fell back to the system font.
- Side panel glued to the stage (1px border only), small header, dense participant rows, host
  controls without clear groups, plain chat bubbles.

==========================================================================================
3. WHAT CHANGED (files)
==========================================================================================
web/src/pages/room/ControlBar.tsx
  - Three zones: left = clock + meeting code (screens >= 1280px); centre = microphone and camera
    (split buttons: main button + joined device chevron), Share, Raise hand, React, Record;
    right = Chat, Participants, Host, divider, Leave.
  - One button style: rounded square, 48px (56px from 1024px), label under the icon from 1024px,
    icon-only with tooltips at 768-1023px, and below 768px a short bar
    (mic, camera, record, More, Leave) with a "More" menu for share, hand, reactions and panels.
  - States: neutral; off (red tint, not solid red); active panel (blue tint); screen share on
    (solid blue); hand raised (amber); restricted by the host (lock + disabled + tooltip).
  - Count badges for unread chat (red) and people waiting (amber).
  - Accessible names (aria-label) kept exactly as before.
web/src/components/ui/overlays.tsx   new Tooltip primitive (Radix).
web/src/main.tsx, web/src/index.css, web/package.json, package-lock.json
  - @fontsource-variable/inter 5.3.0 bundled (served from our own origin; no CSP change).
web/src/pages/room/RoomView.tsx
  - Side panel: floating rounded card with border and shadow from 640px (360px, 400px on large
    screens); bottom sheet with a dimmed backdrop (tap to close) on phones.
web/src/pages/room/PanelChrome.tsx
  - Panel header with icon, title, count chip and close button (chevron on phones); shared
    PanelSection (card) and SettingRow (label + hint left, control right) components.
web/src/pages/room/ParticipantsPanel.tsx
  - Search by name, "In the meeting - n" heading, notice when people are waiting (host),

  - Sections as cards (Waiting room, Audio, Media permissions, Meeting settings, Cloud recording),
    every switch row aligned with a hint; subdued "Mute everyone" button; waiting list rows with

web/src/pages/room/ChatPanel.tsx
  - Messages grouped by sender (name, avatar and time once), rounded bubbles, empty state,
    40px input and Send button, tidier tabs.

6. INDEPENDENT QA FINDINGS (NOT FIXED - awaiting approval)
==========================================================================================
High
 Q1  Chat: a long unbroken word / URL does not wrap; the message list scrolls sideways
     (regression of the new bubble layout). Fix: overflow-wrap:anywhere / max-w-full on the bubble.
 Q2  Host's participant actions menu (about 550px tall) runs off the bottom of the screen for lower
     rows; "Remove from meeting" can become unreachable. Fix: limit its height to the available
     space with scrolling, or move the media permissions into a submenu.
Medium
 Q3  Inter is not used inside the meeting room: LiveKit's own stylesheet sets a system font on the
     room container, which the bar, header and panels inherit. Fix: set the room container's font to
     the app font.
 Q4  Phone "More" menu: the emoji row (8 emoji) is wider than the menu; two are hidden and keyboard
     arrowing shifts the menu sideways. Fix: wrap into rows.
 Q5  Visible label vs spoken name differs in three states (restricted "Unmute", "Stop share",
     "REC 00:02"). Fix: start each accessible name with the visible text.
 Q6  At about 640px with a panel open the video area is only about 256px wide. Fix: use the bottom
     sheet up to 768px.
Low
 Q7  Escape does not close a side panel; opening a panel from the phone menu does not move focus
     into it.
 Q8  Phone "More" badge adds unread chat and waiting people into one red number.
 Q9  At 1280px (host) the centre and right groups are only 12px apart; the centre group is a bit
     off-centre.
 Q10 Some labelled buttons are wider (Participants, Stop share, REC), so the bar shifts slightly
     when sharing or recording starts.
 Q11 No tooltip on the icon-only Leave button at 768-1023px.
 Q12 Two separators in a row in the host's participant actions menu.
 Q13 Host controls panel shows the light system scrollbar on the dark background.
 Q14 The focusable wrapper around a disabled (restricted) button has no role or name.
 Q15 To check, probably older than this change: no raised-hand marker on video tiles; in a webinar,
     attendees appear as "Attendee" in the host's participants list instead of their name.
